CanopyRadiation.MixedLambertianFaces — Type
MixedLambertianFaces(lambertian_fraction)

Convex mixture λ ∈ [0, 1] between two-face Lambertian emission (λ = 1) and face-symmetric isotropic emission (λ = 0):

\[J(\mathbf{\Omega}_r) = \lambda J_{\text{Lambertian}}(\mathbf{\Omega}_r) + (1 - \lambda)\frac{\text{front} + \text{back}}{4\pi} \ge 0.\]

Preserves nonnegativity on the entire sphere, exact total escape upward + downward == front + back, and exact consistency between directional solid-angle integration and leaf_hemispheric_emission.

Examples

julia> law = MixedLambertianFaces(0.7);

julia> h = leaf_hemispheric_emission(law, 0.5, 0.6, 0.2);

julia> isapprox(h.upward + h.downward, 0.8; atol = 1e-15)
true

CanopyRadiation.couple_emission — Method
couple_emission(canopy::AngularEmissionBoundary, atmosphere::AbstractAtmosphericTransfer)

Solve coupled canopy-atmosphere multiple scattering (U = (I - R_c R_a) \ e, D = R_a U, TOA = T_a U), returning (; canopy_up, canopy_down, top_up).

Supports compatible mixed primal and automatic-differentiation scalar types.

Examples

julia> b = AngularEmissionBoundary([0.2;;], [1.0;;], [0.7], [1.0], 0);

julia> atm = AngularAtmosphericTransfer([0.1;;], [0.8;;], [0.7], [1.0], 0);

julia> c = couple_emission(b, atm);

julia> isapprox(c.canopy_up[1, 1], 1.0 / (1.0 - 0.02); atol = 1e-15)

CanopyRadiation.source_projection — Method
source_projection(leaf_cosine, leaf_azimuth, source_cosine, source_azimuth)

Compute the signed Cartesian inner product between the upward-referenced anatomical front leaf normal (leaf_cosine, leaf_azimuth) and the unit vector pointing toward a radiation source (source_cosine, source_azimuth).

Evaluates polar sines via unit_sin_from_cos on each cosine prior to scalar promotion so zenith illumination (|source_cosine| == 1) produces zero NaN partials under automatic differentiation with respect to other inputs.

Examples

julia> source_projection(1.0, 0.0, 0.5, 1.2)
0.5
CanopyRadiation.unit_sin_from_cos — Function
unit_sin_from_cos(mu)

Evaluate sqrt(max(0, (1 - mu) * (1 + mu))) cleanly across primal floats and automatic-differentiation dual numbers.

When (1 - mu) * (1 + mu) is identically zero (exact_zero_scalar) or has a nonpositive primal value (such as mu = ±1 at zenith illumination or nadir viewing), return zero(typeof(mu)) directly without invoking sqrt at zero, avoiding singular NaN tangents when differentiating with respect to other parameters.

Examples

julia> CanopyRadiation.unit_sin_from_cos(0.6)
0.8

julia> CanopyRadiation.unit_sin_from_cos(1.0)
0.0

CanopyRadiation.LeafEmissionMatrix — Type
LeafEmissionMatrix(front, back, reabsorbed)
LeafEmissionMatrix(front, back, reabsorbed, out_of_window)

Conditional photon-fate tables after internal fluorescence production.

Rows index emission bins in the active transport window and columns index excitation channels. Each column sums across front, back, reabsorbed, and the out_of_window long-wavelength / short-wavelength tail fraction to unity:

\[\sum_m (\text{front}_{m,e} + \text{back}_{m,e} + \text{reabsorbed}_{m,e}) + \text{out\_of\_window}_e = 1.\]

The three-argument constructor initializes out_of_window to zeros sharing axes(front, 2).

Examples

julia> m = LeafEmissionMatrix([0.35;;], [0.25;;], [0.30;;], [0.10]);

julia> validate_leaf_emission(m; atol = 1e-12) === nothing
true

CanopyRadiation.build_leaf_emission_matrices — Method
build_leaf_emission_matrices(spectrum, support, excitation_nm, emission_escapes, births; window_indices = eachindex(spectrum.wavelength_nm), out_of_window_fraction = nothing, atol = ...)
build_leaf_emission_matrices(spectrum, support, excitation_nm, emission_escapes, front_births, back_births; window_indices = eachindex(spectrum.wavelength_nm), out_of_window_fraction = nothing, atol = ...)

Construct a validated LeafEmissionMatrix from a fluorophore TabulatedPhotonSpectrum, an AbstractEmissionSupport (StrictStokes() or FullEmissionSupport), excitation_nm, per-emission-bin leaf escape operators emission_escapes (RegularPlateEscape or DorsiventralPlateEscape), and birth-depth profiles (births for n_excite columns, or front_births and back_births for 2 * n_excite anatomical-face columns).

When window_indices selects a proper subset of spectrum (such as 640–850 nm from a full 600–1200 nm fluorophore table), emission_probabilities is conditioned on the full table prior to window slicing so in-window probabilities are never falsely renormalized and out_of_window records the exact excitation-dependent tail fraction.
