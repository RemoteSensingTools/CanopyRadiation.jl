Hemispheric SIF, Spectral Bases, & Kernels

Conservative spectral grid pullbacks, anchor bases, hemispheric source projection, multi-bin canopy SIF transport, KernelAbstractions batch kernels, and CUDA storage adaptation.

Spectral Grid Pullbacks & Anchor Bases

CanopyRadiation.AbstractSpectralMap — Type
AbstractSpectralMap{FT<:AbstractFloat}

Supertype for nonnegative point-response spectral interpolation operators (IdentitySpectralMap and LinearSpectralMap).

CanopyRadiation.IdentitySpectralMap — Type
IdentitySpectralMap(grid)

Identity spectral map on a copied, validated strictly increasing wavelength grid.

Examples

julia> m = IdentitySpectralMap([400.0, 550.0, 700.0]);

julia> source_grid(m) == target_grid(m)
true
CanopyRadiation.LinearSpectralMap — Type
LinearSpectralMap(anchors, targets)

Nonnegative piecewise-linear interpolation map from anchors to targets without extrapolation (first(anchors) <= first(targets) and last(targets) <= last(anchors)).

Examples

julia> m = LinearSpectralMap([400.0, 700.0], [400.0, 550.0, 700.0]);

julia> source_basis_weights(m)
3×2 Matrix{Float64}:
 1.0  0.0
 0.5  0.5
 0.0  1.0
CanopyRadiation.anchor_amplitudes — Method
anchor_amplitudes(front, back, basis; populations = axes(front, 2))

Assemble (population × channel) basis amplitudes from unit-boundary face responses front and back of shape (anchor, population, boundary) and basis prepared by prepare_anchor_basis.

CanopyRadiation.map_spectrum! — Method
map_spectrum!(dest, map::AbstractSpectralMap, src)

Interpolate first-axis point responses from src into dest along map, preserving all trailing batch dimensions.

CanopyRadiation.prepare_anchor_basis — Method
prepare_anchor_basis(map, incident_bins, eta, model, internal_probability, excitation_energy; atol)

Prepare exact algebraic anchor-channel excitation and emission pullback tables for direct/diffuse boundary incident_bins (n_native × 2), photosystem selection fraction eta (n_native), anatomical-face model (n_emit × 2n_native), in-window internal_probability (n_emit × 2n_native), and excitation_energy.

Enforces full photon conservation across in-window internal_probability plus model.out_of_window both before and after basis reduction.

CanopyRadiation.prepare_emission_basis — Method
prepare_emission_basis(model::LeafEmissionMatrix, excitation_spectra; atol)

Reduce model onto normalized conditional excitation basis columns from nonnegative (excitation × basis) excitation_spectra, propagating front, back, reabsorbed, and out_of_window while preserving exact column-sum conservation.

Return (; totals, active, model, conditional_excitation) where model === nothing when all basis columns are identically zero.

CanopyRadiation.source_basis_weights — Method
source_basis_weights(map::AbstractSpectralMap)

Return the (n_target, n_source) partition-of-unity weight matrix of map for exact algebraic excitation pullback.

CanopyRadiation.source_grid — Method
source_grid(map::AbstractSpectralMap)

Return the read-only source/anchor wavelength vector of map.

CanopyRadiation.target_grid — Method
target_grid(map::AbstractSpectralMap)

Return the read-only target/native wavelength vector of map.

CanopyRadiation.validate_basis_amplitudes — Method
validate_basis_amplitudes(amplitudes, n_basis)

Validate that (population × n_basis) basis amplitudes are finite and nonnegative across all original basis columns (including inactive ones).

Hemispheric Moments & Source Expansion (Scalar and Batch Kernels)

CanopyRadiation.batch_expand_hemispheric_sources! — Method
batch_expand_hemispheric_sources!(up, down, plus, minus, front, back)

Expand (n_emit × n_channel) conditional face tables front and back against (n_depth × n_channel) hemisphere moments plus and minus into (n_depth × n_emit) sources up and down on CPU, OffsetArray, or GPU (CuArray).

CanopyRadiation.batch_hemispheric_moments! — Method
batch_hemispheric_moments!(plus, minus, law, mu, weighted)

Compute batched (n_depth × n_channel × n_batch) hemisphere moments plus and minus from (n_orient × n_depth × n_channel × n_batch) weighted sources on CPU, OffsetArray, or GPU (CuArray).

CanopyRadiation.expand_hemispheric_source! — Method
expand_hemispheric_source!(up, down, plus, minus, front, back)

Expand one emission bin's conditional face escapes front and back against hemisphere moments plus and minus into depth-resolved hemispheric sources up and down across CPU, OffsetArray, and GPU arrays.

CanopyRadiation.hemispheric_bin — Method
hemispheric_bin(plus, minus, front, back, depth_idx)

Expand conditional channel escapes front and back against pre-integrated hemisphere moments plus[depth_idx, :] and minus[depth_idx, :] into (; up, down) hemispheric source strengths at depth_idx.

CanopyRadiation.hemispheric_moment — Method
hemispheric_moment(law::AbstractEmissionAngularLaw, mu, weighted, depth_idx, channel_idx)

Reduce orientation-weighted internal channel strength weighted[:, depth_idx, channel_idx] with leaf-normal cosines mu under law into (; plus, minus) hemisphere moments at (depth_idx, channel_idx), respecting generic array axes.

CanopyRadiation.hemispheric_source_moments! — Method
hemispheric_source_moments!(plus, minus, law::AbstractEmissionAngularLaw, mu, weighted)

Compute (depth × channel) hemisphere moments plus and minus from leaf normal cosines mu ([-1, 1]) and nonnegative (orientation × depth × channel) weighted internal sources across CPU, OffsetArray, and GPU arrays.

Layer Hemispheric Sources & SIF Assembly

CanopyRadiation.DualLayerHemisphericSource — Type
DualLayerHemisphericSource(psii, psi)

Pair Photosystem II (psii) and Photosystem I (psi) LayerHemisphericSource objects sharing identical lai, fractional_depths, and depth weights (while permitting distinct active basis channel counts).

Examples

julia> s2 = LayerHemisphericSource(1.5, [0.5], [1.0], [0.4;;], [0.4;;], [1.2]);

julia> s1 = LayerHemisphericSource(1.5, [0.5], [1.0], [0.1;;], [0.1;;], [0.3]);

julia> ds = DualLayerHemisphericSource(s2, s1);

julia> ds.psii.lai == ds.psi.lai
true
CanopyRadiation.LayerHemisphericSource — Type
LayerHemisphericSource(lai, fractional_depths, weights, plus, minus, physical_channels)

Store pre-reduced unit-interval fractional_depths ∈ [0, 1], quadrature weights, (depth × channel) hemisphere moments plus and minus (per unit LAI), and ground-area integrated physical_channels (μmol internal photons per m² ground per s) for one canopy layer and one photosystem class.

Storing fractional_depths directly in [0, 1] avoids singular division by lai at empty layers (lai == 0) and preserves smooth automatic differentiation with respect to lai.

Examples

julia> lhs = LayerHemisphericSource(1.5, [0.5], [1.0], [0.4;;], [0.4;;], [1.2]);

julia> lhs.lai
1.5
CanopyRadiation.evaluate_hemispheric_sif_bin — Method
evaluate_hemispheric_sif_bin(layers, emission_model, absorption_rates, backscatter_rates, soil_reflect, bin::Integer)

Evaluate canopy hemispheric fluorescence transport and layer photon-fate budgets for emission bin across single-photosystem (AbstractVector{<:LayerHemisphericSource} with LeafEmissionMatrix / NoLeafEmission) or dual-photosystem (AbstractVector{<:DualLayerHemisphericSource} with DualLeafEmissionMatrix or NoLeafEmission) inputs, supporting mixed primal optical matrices and automatic-differentiation dual layer sources.

Return (; down, up, absorption, ground, generated, internal, within_leaf, escaped).

CanopyRadiation.evaluate_hemispheric_sif_spectrum — Method
evaluate_hemispheric_sif_spectrum(layers, emission_model, absorption_matrix, backscatter_matrix, soil_spectrum)

Evaluate canopy hemispheric fluorescence spectra across all n_emit bins, where absorption_matrix and backscatter_matrix have (n_emit, n_layers) shape and soil_spectrum has length n_emit.

Return (; top, ground, generated, layer_absorption, internal, within_leaf, escaped, out_of_window) recording the full 5-fate column photon ledger (top + sum(layer_absorption) + ground ≈ sum(escaped), sum(internal) + sum(out_of_window) == total_created_photons).

Device Storage Adaptation

CanopyRadiation.adapt_radiation_storage — Method
adapt_radiation_storage(target, x)

Transfer array-backed radiation objects (QuadratureEmission, AngularEmissionBoundary, AngularAtmosphericTransfer, LeafEmissionMatrix, DualLeafEmissionMatrix, LayerHemisphericSource, DualLayerHemisphericSource, ColumnFluxWorkspace, EmittingColumnWorkspace) onto array container type target (such as Array or CuArray when CUDA is loaded).

Every array field is transferred (ranges and static vectors become arrays of the target type with the same element type), nested records are transferred recursively, and scalar fields are kept. Objects are rebuilt through their constructors, so dimension checks run again; QuadratureEmission and LayerHemisphericSource skip their value checks (validate = false), which would otherwise read device memory element by element.
