CanopyRadiation — Module
CanopyRadiation

Provide modular canopy-column radiative transfer, thermal and fluorescence volume-emission cavity solvers, anatomical leaf-face illumination, conditional single- and dual-photosystem leaf spectral escape matrices, spectral basis pullbacks, and hemispheric source coupling on CPU and GPU.

CanopyRadiation builds directly on public CanopyOptics leaf and canopy scattering types without depending on vSmartMOM, leaf physiology, or host atmospheric state packages, preserving acyclic composition across Float32, Float64, OffsetArray, CuArray, and ForwardDiff automatic differentiation.
