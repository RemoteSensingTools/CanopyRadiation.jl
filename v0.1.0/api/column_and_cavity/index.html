Passive & Emitting Column Solvers

Passive two-stream canopy layer operators, column workspaces, and unified volume-emission cavity solvers for longwave thermal radiation and solar-induced chlorophyll fluorescence.

Passive Two-Stream Column Solvers

CanopyRadiation.AbstractTwoStreamMethod — Type
AbstractTwoStreamMethod

Supertype for homogeneous-slab two-stream operator closures (NativeTwoStream and AnalyticTwoStream).

CanopyRadiation.AnalyticTwoStream — Type
AnalyticTwoStream()

Closed-form homogeneous two-stream layer closure without thin-slab halving or doubling loops.

Evaluates diffuse reflection/transmission and direct-beam coupling analytically in an r_∞-free Green's-function form that remains nonsingular and smooth under automatic differentiation across conservative scattering (α → 0), resonant beam extinction (k → m), and optically thick slabs.

Examples

julia> AnalyticTwoStream()
AnalyticTwoStream()
CanopyRadiation.CanopyRates — Type
CanopyRates(absorption, backscatter, beam_up, beam_down, extinction)

Store differential two-stream coefficients per unit one-sided leaf area index (LAI), where diffuse attenuation is a = absorption + backscatter.

Fields

  • absorption::FT: diffuse absorption rate α = a - b per unit LAI.
  • backscatter::FT: diffuse backward scattering rate b per unit LAI.
  • beam_up::FT: upward diffuse scatter from direct beam s_b per unit LAI.
  • beam_down::FT: downward diffuse scatter from direct beam s_f per unit LAI.
  • extinction::FT: direct-beam extinction rate k per unit LAI.

Examples

julia> r = CanopyRates(0.12, 0.08, 0.05, 0.06, 0.7)
CanopyRates{Float64}(0.12, 0.08, 0.05, 0.06, 0.7)
CanopyRadiation.ColumnFluxWorkspace — Type
ColumnFluxWorkspace(::Type{FT}, n_layers::Integer)
ColumnFluxWorkspace(direct, down, up, absorption)

Hold caller-owned column profile buffers for zero-scratch in-place passive column solves via solve_column!.

direct, down, and up store n_layers + 1 top-to-bottom interface fluxes and share identical index axes; absorption stores n_layers layer totals.

Examples

julia> ws = ColumnFluxWorkspace(Float64, 3);

(4, 3)
CanopyRadiation.LayerOperator — Type
LayerOperator(reflection, transmission, beam_up, beam_down, beam_transmission)

Store the dimensionless scattering and transmission response of a homogeneous canopy layer to unit boundary diffuse and direct-beam fluxes.

Fields

  • reflection::FT: bi-hemispherical diffuse reflectance R.
  • transmission::FT: bi-hemispherical diffuse transmittance T.
  • beam_up::FT: upward diffuse escape at top from unit top horizontal direct beam.
  • beam_down::FT: downward diffuse escape at bottom from unit top horizontal direct beam.
  • beam_transmission::FT: unscattered direct-beam transmittance exp(-k * LAI).

Examples

julia> op = LayerOperator(0.05, 0.72, 0.04, 0.06, 0.5)
LayerOperator{Float64}(0.05, 0.72, 0.04, 0.06, 0.5)
CanopyRadiation.NativeTwoStream — Type
NativeTwoStream(thin_norm, source_terms)
NativeTwoStream(::Type{FT} = Float64; thin_norm = FT(0.05), source_terms = 12)

Specify thin-layer Taylor integration plus adding-doubling controls for homogeneous two-stream canopy layers.

thin_norm bounds the dimensionless sub-slab norm h * max(a + b, k) prior to repeated doubling, and source_terms sets the Taylor order for the direct-beam source column on the thin sub-slab.

Examples

julia> m = NativeTwoStream(0.05, 12)
NativeTwoStream{Float64}(0.05, 12)
CanopyRadiation.diffuse_response — Method
diffuse_response(absorption, backscatter, lai)

Compute exact diffuse slab reflectance, transmittance, and constant/linear volume-emission source moments (; reflection, transmission, source_zero, source_first) for a homogeneous slab of leaf area index lai.

Exponentially scaled expm1 expressions prevent thick-slab overflow, and an e^{+z}-canceled even power series in q = α(α + 2b)L² preserves smooth first- and second-order automatic differentiation all the way through the conservative limit α → 0.

Examples

julia> resp = diffuse_response(0.0, 0.25, 2.0);

julia> isapprox(resp.reflection + resp.transmission, 1.0; atol = 1e-15)
true
CanopyRadiation.foursail_canopy_rates — Method
foursail_canopy_rates(geom::FourSAILGeometry, reflectance, transmittance)
foursail_canopy_rates(geom::FourSAILGeometry, reflectance, transmittance, clumping)

Map precomputed 4SAIL angular geometry geom and leaf hemispherical reflectance and transmittance (plus optional clumping index Ω ≥ 0, defaulting to 1) into differential two-stream CanopyRates.

Leaf absorptance is evaluated internally as 1 - (reflectance + transmittance) so the 4SAIL extinction identity a = absorption + backscatter = 1 - sigf holds identically. Positional arguments allow broadcasting over CPU and GPU wavelength vectors via foursail_canopy_rates.((geom,), reflectance, transmittance).

Examples

julia> using CanopyOptics

julia> geom = FourSAILGeometry(spherical_leaves(); sza_deg = 30.0, vza_deg = 0.0, raa_deg = 0.0);

julia> rates = foursail_canopy_rates(geom, 0.08, 0.06);

julia> isapprox(rates.absorption, 0.86; atol = 1e-14)
true
CanopyRadiation.interior_flux — Method
interior_flux(method, rates, lai, x, down_top, up_bottom, beam_top)

Reconstruct (; down, up, beam) inside a homogeneous layer of total leaf area index lai at local depth x ∈ [0, lai] from solved interface boundary fluxes down_top, up_bottom, and beam_top.

Examples

julia> r = CanopyRates(0.15, 0.08, 0.04, 0.05, 0.65);

julia> m = AnalyticTwoStream();

julia> op = layer_operator(m, r, 1.4);

julia> sol = solve_column((op,), 0.8, 0.2, 0.1);

julia> mid = interior_flux(m, r, 1.4, 0.7, sol.down[1], sol.up[2], sol.direct[1]);

julia> mid.down > 0 && mid.up > 0 && mid.beam > 0
true

layer_operator(method::AbstractTwoStreamMethod, rates::CanopyRates, lai)

CanopyRadiation.solve_column! — Method
solve_column!(ws::ColumnFluxWorkspace, layers::AbstractVector{<:LayerOperator}, direct, diffuse, soil)

Solve a top-to-bottom stack of LayerOperators over Lambertian ground reflectance soil into ws with zero scratch allocations.

During the backward adding sweep, ws.down and ws.up temporarily hold interface effective reflectance and beam-induced upward source before being overwritten in place during the forward flux sweep, matching solve_column in exact IEEE-754 arithmetic order.

CanopyRadiation.solve_column — Method
solve_column(layers, direct, diffuse, soil)

Solve a top-to-bottom stack of LayerOperators (NTuple or AbstractVector) under top horizontal direct and diffuse incident fluxes above Lambertian ground reflectance soil.

Return (; direct, down, up, absorption, ground) satisfying column flux conservation direct[1] + diffuse == up[1] + sum(absorption) + ground.

Examples

julia> r = CanopyRates(0.15, 0.08, 0.04, 0.05, 0.65);

julia> ops = (layer_operator(AnalyticTwoStream(), r, 1.0), layer_operator(AnalyticTwoStream(), r, 1.5));

julia> sol = solve_column(ops, 0.7, 0.3, 0.15);

julia> isapprox(sol.up[1] + sum(sol.absorption) + sol.ground, 1.0; atol = 1e-14)
true

CanopyRadiation.solve_emitting_column! — Method
solve_emitting_column!(ws::EmittingColumnWorkspace, layers::AbstractVector{<:EmittingLayer}, down_top, soil_reflect, soil_emit)

Solve a diffuse cavity with internal layer emission, top downward boundary flux down_top (such as sky thermal longwave), ground reflectance soil_reflect, and upward ground emission soil_emit into ws with zero scratch allocations.

Return (; down, up, net_layer, absorption, net_soil, ground_absorbed, generated) satisfying both net divergence balance (down_top - up[1] == sum(net_layer) + net_soil) and gross radiative balance (down_top + generated + soil_emit == up[1] + sum(absorption) + ground_absorbed).

CanopyRadiation.solve_emitting_column — Method
solve_emitting_column(layers, down_top, soil_reflect, soil_emit)

Solve a top-to-bottom stack of EmittingLayers (NTuple or AbstractVector) under top downward flux down_top, Lambertian ground reflectance soil_reflect, and upward ground emission soil_emit.

Return the 7-field NamedTuple (; down, up, net_layer, absorption, net_soil, ground_absorbed, generated).

Examples

julia> l1 = emitting_layer(0.9, 0.05, 1.2, UniformEmission(180.0, 180.0));

julia> sol = solve_emitting_column((l1,), 320.0, 0.04, 390.0);

julia> isapprox(320.0 + sol.generated + 390.0, sol.up[1] + sum(sol.absorption) + sol.ground_absorbed; rtol = 1e-13)
true
